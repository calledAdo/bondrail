| Import | What it gives you |
|---|---|
| `@bondrail/sdk/client` | `bondrailClient({ publicClient, walletClient, factory })`: `createAccount`, `bindProject`, `createBond`, `activate`, `releaseSecond`, `sweep`, `withdraw`, `deposit`, `redeem`, `depositAllowed`, `creditHistory` |
| `@bondrail/sdk/permit` | `signAccountPermit`: an EIP-2612 permit for the account, for one-transaction Native payments |
| `@bondrail/sdk/x402` | `handlePaidRequest`, `exactUsdcRequirements`, `httpFacilitator`, `bondrailManifest`, `manifestResponse` |
| `@bondrail/sdk/x402-guard` | `bondrailGuard`, `isBondrailAccount`, `pinFromBond`: buyer-side payTo verification, pinned to a bond's account |
| `@bondrail/sdk/abis` | Generated ABIs for every protocol contract |

Every write simulates first, sends with a padded gas limit (Monad bills the limit) and waits for a successful
receipt.
