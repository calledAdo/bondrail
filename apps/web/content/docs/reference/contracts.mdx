## Facilitator (HTTP service)

The facilitator submits `BondrailAccount.settle`; it is not a separate Solidity contract. Its gas-wallet
address comes from `roles.facilitator` in the selected manifest on the [deployment page](/docs/reference/deployments).

| Endpoint | Purpose |
| --- | --- |
| `GET /supported` | Configured x402 scheme/network capabilities |
| `POST /verify` | Validate signed offer and simulate account settlement |
| `POST /settle` | Journal and submit settlement; success requires a successful receipt |
| `GET /health` | Gas balance/budget, pending nonce and recovery state in the current service code |

POST bodies contain `{x402Version: 2, paymentPayload, paymentRequirements}`. See the
[x402 guide](/docs/guides/x402) for funding, retries and reconciliation, and the
[service source](https://github.com/calledAdo/bondrail/tree/main/services/facilitator).
