<Callout type="warn">Monad testnet; not audited. The current Bondrail deployment includes the
vault and credit registry. Historical immutable contracts do not gain features from source updates.</Callout>

Production is [bondrail.vercel.app](https://bondrail.vercel.app), serving `main`.
`BONDRAIL_DEPLOYMENT` defaults to `main` and loads `docs/deployments/10143.json` for
Monad testnet. `NEXT_PUBLIC_CHAIN_ID` selects the chain; a named selection such as
`BONDRAIL_DEPLOYMENT=staging` loads `<chainId>-staging.json`. Rebuild after changing
selection, and point the wallet configuration and indexer at the same deployment.
All addresses below are read at build time through `deploymentPath`; no address is copied into MDX.

The table includes `BondrailVault`, `BondrailCreditRegistry`, curator/attester and the
facilitator gas wallet when present. An absent row means the manifest provides no address.
The facilitator relays `account.settle`; its wallet does not hold payer funds. The manifest
records identities, not live health or proof that every later code revision has been rolled out.
