Monad testnet; not audited. Query the selected deployment's GraphQL endpoint with any GraphQL client.
The [production runbook](https://github.com/calledAdo/bondrail/blob/main/docs/deployments/RUNBOOK.md)
records its configuration. Production uses project **bondrail-next**, release branch
**envio-next**, and `https://indexer.dev.hyperindex.xyz/1ac5720/v1/graphql`.
Keep that release branch as-is when updating app deployment names. Indexer history is a read model; reconcile important results with the chain.

`BondrailAccount.Settled` attributes account-mediated x402 payments; `Revenue` records the split and
avoids counting that settlement again as Native revenue. `Collected` records Native volume.
Token `AuthorizationUsed` / `Transfer` evidence can attribute direct-to-token x402 receipts. Payment
identities deduplicate settlement and token evidence. Other inflows are unclassified. Native payer
attribution uses account events, including calls through another contract; it is not limited to the
transaction's top-level recipient.

`Bond.triggered` follows `BondrailBond.TriggerChanged`, including recovery; timeline events record
`Triggered` and `TriggerRecovered`. The on-chain trigger sums all booked account revenue, including
self-payments, independently of attributed revenue. `BondRecorded` and `Attested` track registry-scoped
membership and assessment history when the registry is configured. Evaluate expiry and current signer
through `attestedProfile`; stored event history does not establish current validity or completeness.

Funding-link detection is one hop for the indexed asset. “Attributed” means a proven payer without a
detected related-party link under that policy, not an independent customer or delivered service.
Coverage, late indexing and omissions matter; see [credit profiles](/docs/concepts/credit-profiles).
