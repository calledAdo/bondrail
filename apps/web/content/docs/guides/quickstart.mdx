---
title: Quickstart
description: Run Bondrail locally and route your first payment through a BondrailAccount.
---

Testnet/local prototype; not audited. You need Node 22+, pnpm 10.32.0 and Foundry.
For a standalone Solidity integration, use the [external package example](https://github.com/calledAdo/bondrail/tree/next/examples/native-project).

```bash
pnpm install
forge test --root contracts
anvil
```

In another terminal, deploy the protocol and the demo launchpad (a Native project) to the local chain:

```bash
BONDRAIL_CHAIN_ID=31337 pnpm tsx scripts/deploy.ts
BONDRAIL_CHAIN_ID=31337 pnpm tsx demo/scripts/setup-demo.ts pumplab
```

The first run creates the account, has the reviewer approve the PumpLab template hash with
`setNativeTemplate`, then deploys and binds it with `deployNative`. It then stops:
a bond needs real history. Send traffic, then run setup again to issue, fund and activate the bond:

```bash
BONDRAIL_CHAIN_ID=31337 pnpm tsx demo/scripts/traffic-launchpad.ts pumplab organic 1
BONDRAIL_CHAIN_ID=31337 pnpm tsx demo/scripts/setup-demo.ts pumplab
```

Every buy went in through `collect`, every sell out through `settleOut`, and the account's history is on-chain.
Locally the minimum-history wait is skipped by advancing the chain clock; the next testnet manifest configures 10 minutes (`factory.minHistory()`).
