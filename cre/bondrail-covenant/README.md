# Bondrail CRE covenant workflow

This is an actual CRE1.23 workflow: CronCapability → HTTPClient with identical aggregation → observer signature verification and independently fetched offer comparison → runtime.report → EVMClient.writeReport. The report payload is precisely `abi.encode(Observation,bytes signature)`, matching BondrailCovenant. A confirmed receiver execution prints `BONDRAIL_REPORT_TX=<hash>` for the worker; no direct `submitObservation` fallback exists here.

Configure one workflow directory per watch. Copy `../../services/observer/registry.example.json`'s policy into `config.json` using the structure of `config.example.json`; it must be byte-for-byte semantically equal under canonical JSON to the observer's registry policy. Copy `secrets.example.yaml` to `secrets.yaml`, and `../project.example.yaml` to `../project.yaml`. Provide `OBSERVER_API_TOKEN` through the CRE secret mapping. Never place a private key or bearer token in public config. The configured observer signer must match the contract immutable signer.

Install Bun, CRE CLI and the SDK Javy setup according to the pinned SDK instructions. From this folder `pnpm compile` typechecks and compiles a WASM artifact. From `cre/`, `cre workflow simulate bondrail-covenant --target staging-settings --non-interactive --trigger-index 0` is the dry run. For an explicitly authorized funded testnet demonstration append `--broadcast`. The worker supplies the separated flag correctly. Simulation does not demonstrate DON consensus or production oracle decentralization.

The workflow rejects mainnet and unknown selectors. Monad testnet selector is2183018362218727504. Its default mock forwarder is0xB9F79d863261869B234c481D1f9A7af84AeAd192; verify code and contract configuration before use. The mock itself is permissionless. Security against forged reports comes from the immutable observer signer and the Covenant's signature/freshness/replay checks. Production requires the appropriate production forwarder/workflow authorization review.

Unknown monitor results may be reported; consensus failure, disagreement with the signed evidence, invalid signature or stale evidence aborts without a report. Volatile HTTP headers/local node timestamps never enter offer consensus. The observer provides pinned-DNS SSRF enforcement. CRE separately fetches the frozen public HTTPS URL through its HTTP capability; CRE networking behavior is provided by that capability, not Node's observer transport.
